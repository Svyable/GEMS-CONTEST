# Candidate pipeline

The organizer OOF notebook is a baseline diagnostic. A competition candidate must instead train on the available supervision and produce calibrated predictions over the entire valid study region.

## Full-raster inference contract

`src/gems/tiling.py` provides deterministic overlapping windows and seam-reducing cosine blending. Every valid raster pixel is covered, including edge cases where the raster is smaller than the model patch size.

The intended inference flow is:

1. load/derive feature channels and apply fold-pure preprocessing;
2. generate overlapping windows using the experiment's patch size and overlap;
3. run the model on every window;
4. blend probabilities with nonzero cosine weights so overlapping tiles do not create hard seams;
5. apply the official valid-data mask;
6. write the result against the official sample-submission template;
7. run `scripts/validate_submission.py` before any upload.

## Writing a submission-format raster

If a model produces a full-size NumPy probability array:

```bash
uv run python scripts/write_prediction.py \
  --prediction-npy outputs/candidate.npy \
  --template data/raw/example_submission.tif \
  --output submissions/candidate.tif
```

The writer rejects shape mismatches, non-finite predictions inside the valid region, and values outside [0, 1]. It writes float32 and NaN outside the template's valid-data mask, then runs the repository submission validator.

## Validation discipline

Do not select models from the organizer's random-patch OOF loss. Candidate selection should use the buffered spatial folds and complete-fault holdouts generated by `scripts/build_cv_manifest.py`.

Normalization/statistical preprocessing must be estimated from the training region for each fold. Whole-raster feature statistics are allowed only for reproducing the organizer baseline, not for our comparative validation.

## Next implementation layer

The remaining model-side work is to connect this inference plumbing to a train-on-all/fold-aware U-Net training loop, then add derived geophysical/terrain channels as controlled ablations.
